# TP_Estadistica_y_Programacion
# Integrantes: Alvaro Costa Millet, Mauricio Jurado

El repositorio incluye:
1. El script inicial de descarga y manipulación de datos mediante CLI en Bash (`Descarga.sh`).
2. El dataset resultante (`dataset.csv`).
3. El código fuente del análisis estadístico descriptivo elaborado en R y Quarto (`reporte_eda.qmd`).
4. El reporte final renderizado con las medidas de posición y gráficos generados con ggplot2 (`Reporte EDA.pdf`).
5. El dashboard interactivo elaborado en Quarto (`dashboard.qmd` y `_quarto.yml`).
